## ✨ El Despertar

> *Hay momentos donde el entorno digital se vuelve denso, confuso y abrumador. La tecnología suele exigir velocidad, atención constante y datos, ignorando el estado interno de quien está detrás de la pantalla.*

**ÑUHU** nace de la intersección entre la fragilidad humana y la arquitectura digital. No busca ser una herramienta fría de productividad, sino una interfaz consciente que transforma un instante de desorientación y miedo en un espacio seguro de orientación, calma y control progresivo. Un destello de luz en medio de la niebla digital.

## 🐉 ¿Qué es ÑUHU?

**ÑUHU** es una experiencia interactiva y un videojuego experimental que explora cómo la tecnología, la inteligencia artificial y los principios de ciberseguridad pueden unirse para acompañar de forma respetuosa a las personas durante momentos de vulnerabilidad.

* **No** es una plataforma médica ni sustituye la terapia profesional.
* **Es** una exploración de diseño de software enfocado en la empatía, la accesibilidad integral y la protección absoluta de la privacidad del usuario.

## 🧠 Tecnología & Arquitectura

La arquitectura de ÑUHU está diseñada bajo un flujo controlado que prioriza el procesamiento eficiente y la seguridad de los datos en cada capa del sistema:

```text
[ PLAYER ]
    ↓
[ ÑUHU EXPERIENCE ] (Frontend interactivo / React & TypeScript)
    ↓
[ INTERACTION & CONTEXT ] (Captura local de estímulos y flujos)
    ↓
[ INTELLIGENT SUPPORT ] (Modelos de IA orientados a guía y acompañamiento)
    ↓
[ SAFE RESPONSE ] (Respuesta validada y protegida)# ÑUHU Resonance

## Arranque (Windows / Mac / Linux)

```bash
npm install
npm run dev
```

Abre: **http://localhost:3000**

- Aventura VR (portada): http://localhost:3000/nuhu-aventura-vr.html
- Unified (Simon + gestos + tutorial): http://localhost:3000/nuhu-resonance-unified.html

> No hace falta Python. No hay archivos .obj / Blender.
> Los dragones 3D van en formato **.glb** optimizado para web.

## Requisitos

- Node.js 16+ → https://nodejs.org
- Chrome o Edge
- Cámara: solo en **localhost** (no uses 192.168.x.x)
